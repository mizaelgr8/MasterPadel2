1. CÓMO DESCARGAR EL PROYECTO COMPLETO (.ZIP)
-------------------------------------------------------------------------------
Para obtener el archivo con todo el código fuente:
1. Ve al panel lateral o superior de Firebase Studio.
2. Busca el icono de "File" (Archivo) o los tres puntos de opciones del proyecto.
3. Selecciona "Download .zip" o "Descargar Código".
Esto te entregará un paquete listo para subir a GitHub o entregar a un cliente.

3. LAS 5 CAPTURAS QUE DEBES MOSTRAR (TIPS)
-------------------------------------------------------------------------------
Para que tu portafolio destaque, toma screenshots de estas vistas específicas:
1. EL PODIO: En la pestaña Ranking, captura el podio con las coronas doradas. 
   Es lo más visual de la app.
2. PANTALLA PUBLICITARIA: Entra al Modo Proyector y selecciona "Publicidad". 
   Esa vista gigante del logo vende el proyecto como algo corporativo y serio.
3. GESTIÓN DE RESERVAS: Muestra la cuadrícula de las 4 pistas. Demuestra que 
   puedes manejar sistemas de horarios complejos.
4. REGISTRO DE PARTIDAS: Captura el momento en que se ven las canchas en azul. 
   Refleja la utilidad real para un club.
5. LOGIN PREMIUM: La pantalla de inicio con el degradado radial y el logo
